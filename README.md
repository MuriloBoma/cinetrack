# cinetrack

O objetivo é desenvolver uma aplicação web funcional chamada CineTrack: um gerenciador pessoal de listas
de filmes. Nesta parte, toda a lógica reside no navegador, sem servidor e sem banco de dados; os dados são
mantidos localmente.

O trabalho é construído de forma incremental: cada etapa acrescenta um trecho concreto ao projeto, versionado
com commits ao longo do desenvolvimento.
